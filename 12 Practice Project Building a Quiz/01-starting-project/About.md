# React – Working with Effects in Practice

## 1. Section Introduction

In this section, we will build a **brand-new React project from scratch** to practice and strengthen our understanding of React Side Effects and the `useEffect` hook.

The primary goal is to apply previously learned concepts in a practical project and understand how different React concepts work together.

Instead of only learning the theory, we will implement everything step by step while understanding why particular approaches are used.

## 2. Main Objectives of This Section

This section focuses on revisiting and strengthening the following concepts:

### A. Side Effects & useEffect

- Practice implementing side effects in real React components.
- Understand when and why the `useEffect` hook is needed.
- Learn how effects interact with component rendering.

### B. Effect Dependencies

- Understand when to add dependencies to `useEffect`.
- Learn how dependency changes trigger effect re-execution.
- Develop a better understanding of which values should be included in the dependency array.

### C. Cleanup Functions

- Practice implementing cleanup functions.
- Understand when cleanup functions execute.
- Learn how to prevent unwanted behavior and properly manage side effects.

### D. Combining React Concepts

- Combine effects with other React concepts.
- Revisit components and component composition.
- Understand how different React features work together in a complete application.

## 3. Learning Approach

The project will be developed from the ground up, following a step-by-step approach.

The learning process will involve:

1. Understanding the project requirements.
2. Building the application step by step.
3. Applying previously learned React concepts.
4. Understanding why particular implementations are necessary.
5. Practicing independently alongside the instructor.

**Important:** The objective is not simply to complete the project but to understand the reasoning behind every implementation.

## 4. Practice Opportunity

You can also attempt to build the entire project independently before following the instructor.

This provides an opportunity to:

- Test your existing React knowledge.
- Identify gaps in your understanding.
- Practice working with effects.
- Improve your ability to structure React applications.
